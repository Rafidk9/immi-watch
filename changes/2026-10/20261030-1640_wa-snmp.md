### 🔴 WA State Nominated Migration Program (subclasses 190 and 491) approved applications will carry over to the next program year if nomination places run out
_Migration WA – State Nominated Migration Program_

**What changed**
- WA Migration Services has clarified that if an application for State nomination is approved but nomination places are unavailable in the current program year, the application will be carried over to the next program year.
- Approved applications remain subject to the availability of nomination places within the program year (1 July to 30 June).
- Minor editorial change lowercase 'terms and conditions of WA State nomination'.

**Who it affects:** WA State nomination (subclass 190 and 491) applicants whose applications are approved when program year allocation quotas have been exhausted.

**What to do:** Inform clients that approved nominations will not be lost if WA exhausts its allocation before the end of the program year, as they will now carry over automatically into the next program year.
